# Scouty.ca design handoff

This folder contains the approved homepage direction and the implementation brief for Copilot.

## Files

- `COPILOT_PROMPT.md` — paste into Copilot Agent mode with the full repository open.
- `design-tokens.css` — approved colours, fonts, radii, shadows, and gradients.
- `assets/scouty-homepage-reference.png` — visual source of truth; do not ship it as the page.
- `assets/scouty-hero-background.png` — background-only hero artwork.
- `assets/scouty-hero-mascot.png` — standalone Scouty illustration for responsive placement.
- `assets/scouty-favicon.ico` — existing multi-resolution favicon.

The product name is **Scouty.ca**. The raccoon guide is **Scouty**. **JamesAI** remains the internal recommendation engine and may appear only in subtle copy such as “Recommendations powered by JamesAI.”
